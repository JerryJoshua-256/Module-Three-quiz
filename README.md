# Module 3 Urban Design Quiz — Vercel deployment

This is a static website and needs no database, email service, API key or backend.

## Deploy
1. Extract this ZIP.
2. Open the `module-3-quiz` folder and confirm `index.html` is at its top level.
3. Sign in to Vercel and select **Add New → Project**.
4. Import the folder through a GitHub repository or deploy it with the Vercel CLI.
5. No build command is required. Use the project root as the output directory if prompted.
6. Deploy. Vercel will provide a `.vercel.app` address.
7. For a custom domain, add it under Project → Settings → Domains, then configure the exact DNS records Vercel displays at your domain registrar.

## Edit the welcome message
Open `index.html` in VS Code and search for `Welcome, Maryam`.
